# Архитектура: отбор «Только изменённые объекты»

## Что делает

Кнопка-переключатель на панели инструментов Навигатора EDT. Когда нажата, в Навигаторе видны только объекты метаданных, изменённые в рабочей копии Git, и путь к ним. Пустые группы («Справочники», если там ничего не менялось) скрываются.

## Решения

| Вопрос | Решение |
|---|---|
| Что считать изменённым | Незакоммиченные изменения в Git: изменённые, новые (в т.ч. не добавленные в индекс), конфликтные файлы |
| Детализация | Изменённый объект показывается целиком: все реквизиты, формы, макеты |
| Проекты | Отбор применяется к конфигурациям и расширениям. Внешние обработки/отчёты и прочие проекты показываются целиком |
| Удалённые объекты | Пока не показываются (их нет в Навигаторе). Позже отдельный узел или окно |
| Кнопка | Только иконка на панели Навигатора. Две иконки: выключено (контурная воронка) / включено (залитая), обе с оранжевой «дельтой». Подсказка меняется: «Показать только изменённые объекты» / «Показать все объекты» |
| Состояние | При запуске EDT отбор всегда выключен (решение Германа, 0.2.3) |

## Данные из EDT 2026.1.1

- Вид Навигатора и его дерево: `com._1c.g5.v8.dt.ui2.navigator` (Common Navigator).
- Natures: `com._1c.g5.v8.dt.core.V8ConfigurationNature`, `...V8ExtensionNature`, `...V8ExternalObjectsNature`.
- Узлы дерева: объекты EMF `com._1c.g5.v8.dt.metadata.mdclass.*` и адаптеры групп `com._1c.g5.v8.dt.md.ui.navigator.adapters.*NavigatorAdapter$Folder`.
- EGit / JGit 6.8.12.

## Модули и классы

```
core
  edt/EdtNatures            ID natures проектов EDT
  edt/ProjectKind           вид проекта: конфигурация / расширение / внешние объекты / прочее
  changes/MdObjectRef            ссылка на объект: тип (имя класса модели) + имя
  changes/ChangedObjectsSnapshot неизменяемый снимок изменённых объектов по проектам
  changes/IChangeSource          источник изменённых файлов
  changes/ChangeTracker          подписка, пересчёт в фоне с задержкой 300 мс
  edt/EdtSourcePaths             src/<Папка>/<Имя>/... → объект; таблица «папка → тип»
  edt/EGitChangeSource           кэш Git-статуса EGit (внутренний API EGit 6.8!)

ui
  edt/EdtNavigator          ID вида, поиск дерева навигатора
  edt/EdtNavigatorNodes     распознавание узлов: проект, объект EMF, папка (getContentFeature через reflection)
  navigator/changedonly/
    ToggleChangedOnlyHandler    кнопка: переключение, иконка и подсказка по состоянию
    ChangedOnlyFilterController подключает фильтр ко всем открытым навигаторам
    ChangedOnlyStartup          восстанавливает отбор при запуске EDT
    ChangedOnlyFilter           фильтр дерева (правила видимости узлов)
```

## Поток данных (целевой)

```
EGit (кэш статуса) ─► IChangeSource ─► ChangeTracker ─► ChangedObjectsSnapshot (неизменяемый)
                                            │ уведомление (с задержкой ~300 мс)
                                            ▼
                                     ChangedOnlyFilter ─► Навигатор (refresh)
```

- Путь файла → объект метаданных: `src/Catalogs/Номенклатура/...` → `Catalog.Номенклатура` (таблица «папка → тип» в одном месте).
- Внутренний кэш EGit спрятан за `IChangeSource`; запасная реализация — публичный API JGit.
- Распознавание типа узла навигатора — в одном классе `ui.edt`, так как это внутренности EDT.

## Этапы

1. **Каркас** — модули, сборка, кнопка, диагностика узлов. ✓ (0.1.0)
2. **Сервис изменений** ✓ (0.2.0)
3. **Фильтр** — скрытие неизменённого, обновление при смене Git-статуса. ✓ (0.2.0)
4. **Доводка** — иконки, положение кнопки, производительность на больших изменениях. ← сейчас

## Устройство узлов навигатора (EDT 2026.1, по диагностике)

| Узел | Класс | Как распознаём |
|---|---|---|
| Проект | `IProject`, родитель — WorkspaceRoot | `instanceof IProject` |
| Корень конфигурации | `mdclass.impl.ConfigurationImpl` | EClass `Configuration` |
| Папка («Справочники») | `md.ui.navigator.adapters.*NavigatorAdapter$Folder` | `getContentFeature()` → тип элементов ссылки |
| Группа «Общие» | `CommonNavigatorAdapter` | по дочерним узлам |
| Объект | `mdclass.impl.CatalogImpl` и т.п. | EClass + атрибут `name` |

Родитель любого узла внутри проекта передаётся фильтру как `TreePath`, первый сегмент — проект.
