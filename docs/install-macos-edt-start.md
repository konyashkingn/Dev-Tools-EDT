# Установка плагинов в EDT, запущенный через 1C:EDT Start (macOS)

## Симптом

Плагин ставится через **Справка → Установить новое ПО** без ошибок и виден в «Установленном ПО», но после перезапуска не загружается: его нет на вкладке «Подключаемые модули», кнопки и команды не появляются. Это касается **любых** доустановленных плагинов, не только MNT DevTools.

## Причина

EDT Start создаёт профиль установки p2 с `installFolder = <EDT>.app/Contents/MacOS` и без явной папки конфигурации. Установщик пишет список модулей в `Contents/MacOS/configuration`, а EDT запускается с `-configuration ../Eclipse/configuration` и читает его оттуда. На Windows и Linux такой вложенности нет, поэтому проблема только на macOS.

## Исправление (один раз на каждую установку)

1. Проверить: `bash tools/fix-edt-start-p2-config.sh --check`
2. Закрыть EDT (Cmd+Q) и исправить: `bash tools/fix-edt-start-p2-config.sh`
3. Открыть EDT и установить плагин штатно через «Установить новое ПО».

Скрипт добавляет в профиль свойство `org.eclipse.equinox.p2.configurationFolder = <EDT>.app/Contents/Eclipse/configuration` новым состоянием профиля. Перед правкой профиль сохраняется в `~/edt-p2-profile-backup-….tgz`. Откат: удалить созданный файл состояния (путь выводится скриптом).

После обновления или переустановки EDT через EDT Start проверку стоит повторить.

## Побочный эффект

Первая установка после исправления запишет в конфигурацию всё, что числится в профиле. Плагины, которые раньше «ставились, но не работали», начнут загружаться.
